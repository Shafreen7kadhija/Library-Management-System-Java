# Library Management System (Java)

A simple Java Console Application built using Object-Oriented Programming concepts.

## Features

- Add Book
- View Books
- Search Book
- Borrow Book
- Return Book

## Technologies Used

- Java
- OOP
- ArrayList
- Scanner

## How to Run

1. Compile:
   javac *.java

2. Run:
   java Main
